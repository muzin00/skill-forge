Merge the current branch's PR via `gh pr merge --squash --delete-branch`. First inspects PR state and CI status (`gh pr view --json state,url,statusCheckRollup`); if checks are still running, waits via `gh pr checks --watch`. Skips the merge (returns `{ merged: false, prUrl }`) when the PR is not open or any check failed. After a successful merge, switches to `main` and pulls the latest. Throws if the PR doesn't exist or any underlying command fails.
