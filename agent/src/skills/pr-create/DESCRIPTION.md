Create a GitHub Pull Request from the current branch. Reads the branch name (which follows the `{prefix}/{issue-number}/{summary}` convention from CONTRIBUTING.md) to derive the Issue number and commit type, gathers commits/diff against the base ref (default `main`), generates a Conventional-Commits-style title and a `## 概要` + `Closes #N` body, pushes the branch with `git push -u`, then runs `gh pr create`.
