Render the SKILL.md and DESCRIPTION.md file contents for a forge skill being exported. Pure templating: takes a skill name, DESCRIPTION.md text, and the input/output JSON Schemas (plus optional `positionalProp` name) and returns the file bytes. Used by `forge export` to materialise the canonical `~/.skill-forge/exports/<name>/` directory. Validates the description fits the Anthropic Agent Skills 1024-char frontmatter limit.
