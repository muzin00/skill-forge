# skill-forge

A CLI tool that generates and runs sandboxed AI-authored skills.

> ⚠️ **Status**: Early design phase. Not yet usable.

See [Issue #1](https://github.com/muzin00/skill-forge/issues/1) for requirements,
[Issue #2](https://github.com/muzin00/skill-forge/issues/2) for architecture decisions.

## Architecture Overview

skill-forge generates skills via AI and executes them in a sandboxed runtime.
Detailed architecture is being validated through PoCs (tracked under `poc/*` branches).
